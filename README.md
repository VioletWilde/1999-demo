# 微小世界 · 第一、二章 Demo

《重返未来：1999》沙盘场景的非官方交互演示，收录第一章“在我们的时代里”和第二章“夜色温柔”，共 31 幕。

拖动沙盘探索，滚轮或双指缩放。底部片段栏可横向滚动、鼠标拖动或触摸滑动，点击直接跳转；上一幕、下一幕切换相邻片段。章节目录可切换章节，收藏保存在本机浏览器。“更多”提供随机漫游和连续漫游。

默认从第一章开始。所有图片和场景数据均为相对路径，本演示不需要后端和构建步骤。
