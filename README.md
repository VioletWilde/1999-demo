# 微小世界 · 第一、二章 Demo

《重返未来：1999》沙盘场景的非官方交互演示，收录第一章“在我们的时代里”和第二章“夜色温柔”，共 31 幕。

在线体验：https://violetwilde.github.io/1999-demo/

拖动沙盘探索，滚轮或双指缩放。底部片段栏可横向滚动、鼠标拖动或触摸滑动，点击直接跳转；上一幕、下一幕切换相邻片段。章节目录可切换章节，收藏保存在本机浏览器。“更多”提供随机漫游和连续漫游。

“更多 → 隐藏界面”可以收起全部常规界面及底部阴影，保留沙盘拖动和缩放。点击右下角“显示界面”恢复；键盘 U 切换，Esc 恢复。

默认从第一章开始。所有图片和场景数据均为相对路径，本演示不需要后端和构建步骤。

## GitHub Pages

## 视窗覆盖与缩放边界

以背景网格而非前景棋子计算覆盖范围，按屏幕宽高确定最小缩放倍率；拖动、缩放、窗口调整与过渡帧均限制在背景边界内。可继续放大和探索，但不能缩小到露出背景外空白。非矩形特殊场景采用最大底图网格取景。切幕时当前场景先铺底，再叠加上一幕淡出，避免过渡露底。

部署包保留隐藏/恢复界面、手机紧凑布局、相对路径和无构建静态运行方式。31 幕 × 4 种视窗尺寸（124 项）及四角拖动通过验证。部署目录已修改，尚未推送 GitHub。
