# 微小世界 · 主线沙盘漫游

《重返未来：1999》沙盘场景的非官方交互演示，收录当前资源中的全部 14 个主线章节，以及“星”“去往新世界”“船喻”三个间章，共 326 幕。不包含活动剧情。章节目录提供主线、间章和收藏筛选；关卡与章节链接指向灰机 Wiki 对应网页。

在线体验：https://violetwilde.github.io/1999-demo/

拖动沙盘探索，滚轮或双指缩放。底部集中展示当前关卡，上一幕、下一幕切换相邻片段；点击“全部片段”或关卡进度展开完整列表。顶部“探索章节”打开带场景缩略图的章节目录。收藏保存在本机浏览器，“更多”提供随机漫游和连续漫游。

界面采用克制的产品展示风格：轻量文字导航、清晰的中文黑体层级、局部渐变及更少的常驻信息。支持手机竖屏、横屏和键盘操作。

“更多 → 隐藏界面”可以收起全部常规界面及底部阴影，保留沙盘拖动和缩放。点击右下角“显示界面”恢复；键盘 U 切换，Esc 恢复。

默认从第一章开始。所有图片和场景数据均为相对路径，本演示不需要后端和构建步骤。

## 视窗覆盖与缩放边界

以背景网格而非前景棋子计算覆盖范围，按屏幕宽高确定最小缩放倍率；拖动、缩放、窗口调整与过渡帧均限制在背景边界内。可继续放大和探索，但不能缩小到露出背景外空白。非矩形特殊场景采用最大底图网格取景。切幕时当前场景先铺底，再叠加上一幕淡出，避免过渡露底。

部署包保留隐藏/恢复界面、手机紧凑布局、相对路径和无构建静态运行方式，同步已核对的夜景材质与雾孔坐标修正。尚未完整还原游戏的动态粒子、后处理及玩家进度状态。
